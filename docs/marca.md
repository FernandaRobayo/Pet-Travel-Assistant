# Marca de Pet Travel Assistant

Logo original: `frontend/public/logo.svg`, huella blanca sobre verde petróleo y recorrido curvo ámbar. No usa una marca externa.

| Uso | HEX |
| --- | --- |
| Primario | #0F766E |
| Secundario y texto oscuro | #334155 |
| Acento para fondo/borde | #F59E0B |
| Ámbar para texto sobre blanco | #B45309 |

Tipografía aplicada: Arial con fallback sans-serif, definida en el token `--font-outfit`. No se carga una fuente externa. La propuesta inicial Inter no se incorporó; esta ficha declara la fuente efectivamente renderizada.

Demo gratuita: https://nextjs-free-demo.tailadmin.com

Versión del paquete 2.5.0; changelog 2.5.1; se fija el commit. MIT conservada en `frontend/LICENSE-TailAdmin`. Se reutilizan sidebar, tablas, botones, inputs, field, sheet, tooltip, tarjetas y tokens CSS. Se conservan sidebar de 290 px, radios y espaciados; se adaptan logo, paleta, navegación y formularios.

Contraste sRGB: #334155 sobre #F59E0B = 4,82:1; #B45309 sobre blanco = 5,02:1; blanco sobre #0F766E = 5,47:1. Los avisos reales usan fondo ámbar claro y texto oscuro. No se usa ámbar claro como texto ni semáforo.
